# Sky Courier
Sky Courier is a casual 3D game built in Unity.
Click the rotating planet to launch a plane that flies towards you, pauses, and delivers a motivational message before returning back to the planet.

The game combines low-poly 3D visuals with uplifting quotes to create a short, interactive experience.

## Features

Interactive Planet Space – Click and drag the worldspace to reveal a floaty orbit camera around the planet. Clicking the planet will spawn a plane!

Motivational Messages – Each plane delivers a random inspirational message from a user-customized list.

World-Space Main Menu – Start the game from an immersive 3D menu with a smooth camera transition into the world.

Unlocked Messages - Messages that have been viewed already will be saved into an Unlocked Messages menu, to be viewed at any time!

Replayable Experience – Messages are shuffled and will not repeat until all have been viewed to keep interactions fresh (carries over across game sessions).


## Tech

- Unity (version 2022.3.62f1)

- Written in C# using Unity’s component system

- Uses Unity UI (world-space canvases)
